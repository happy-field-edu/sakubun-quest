# 作文マスター・クエスト

小学2年生向け 作文学習Webゲーム。ブラウザだけで動きます（インストール不要・バックエンド不要・外部ライブラリなし）。

## 使い方

- `index.html` をブラウザで開くだけ（iPad Safari 推奨）
- 進捗は端末内の LocalStorage に保存されます（ログイン不要）
- `file://` で開いても動きますが、保存を確実にするならローカルサーバー経由が安全です

```bash
python3 -m http.server 8777
```

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み（タイトル／マップ／バトル／けっか／作文チェック／きろく） |
| `style.css` | 見た目。色・大きさは `:root` の変数でまとめて変更可 |
| `data.js` | **問題データ・ワールド・キャラクター・チェック項目**（ここだけ触れば問題が増える） |
| `script.js` | ゲームのしくみ（進行・判定・演出・保存）。問題追加では触らない |
| `assets/characters/` | 透過PNGのキャラクター画像（勇者・はかせ・各ワールドの敵） |

## 収録数と1回の出題数

| ワールド | 収録問題数 |
|---|---|
| WORLD 1 げんこう用紙の森 | 21問 |
| WORLD 2 文字のどうくつ | 24問 |
| WORLD 3 おしゃべり城 | 21問 |
| WORLD 4 文しょうロード | 24問 |
| WORLD 5 マチガエール魔王城 | 24問 |
| **合計** | **114問** |

1回のバトルではこのうち **10問**（`script.js` の `QUESTIONS_PER_BATTLE`）を出題します。
出題済み回数の少ない問題から優先して選ぶので、繰り返し遊ぶとそのワールドの全問に行き当たります
（例：WORLD 1 は3回プレイで21問すべて出題）。1回の長さを変えたいときは `QUESTIONS_PER_BATTLE` の数字だけ変えてください。

## ステージの解放

- WORLD 1 は最初から遊べます
- **前のワールドをクリアすると次のワールドが開きます**（`script.js` の `isWorldUnlocked()`）
- 未解放のステージはマップ上でグレー表示＋🔒。タップすると「WORLD Nを クリアすると ひらくよ」と案内します
- 初クリア時は結果画面に「🔓 あたらしい ステージが ひらいた！」と、次のワールドへ直接進むボタンが出ます

## 解説の読み時間

正解すると出る解説パネルの「つぎへ」は、**読む時間が経つまで押せません**（その間はバーが伸びて待ち時間を示します）。
待ち時間は「解説の文字数 × 45ms + 2000ms」で、最長5秒。`script.js` の `READ_BASE_MS` / `READ_PER_CHAR_MS` で調整できます。

## 使う漢字について

子どもが読む文（`title` / `childExplanation` / `question` / `hint` / 例文 / 選択肢 / 原稿用紙）は
**小学2年生までに習う漢字（240字）だけ**を使っています。チェックはこのコマンドで行えます。

```
node tools-kanji.js
```

習っていない漢字が使われている箇所を、フィールド名つきで一覧表示します（0か所なら合格）。
解説は1問あたり18〜38字（平均27字）に収めています。

## 問題（ルール）の追加方法

`data.js` の `RULES` に 1 オブジェクト足すだけで、そのワールドの出題プール・敵HP・星の判定に自動で反映されます。

```js
{
  id:'RULE-009',            // 他と重複しない ID
  world:'w1',               // w1〜w5
  type:'rule',              // rule / skill / school_rule
  category:'genkou',        // genkou / moji / kaiwa / bun / kuwashiku（身につき度の分類）
  skill:'一マス空け', difficulty:1,
  title:'ルール名',
  childExplanation:'子ども向けの説明（作文はかせのセリフ）',
  correctExample:'正しい書き方',
  wrongExample:'まちがった書き方',
  hint:'まちがえたときのヒント',
  questionType:'choice',    // ox / choice / find / slot / order / rewrite
  question:'どちらが 正しいかな？',
  choices:[ {text:'…'}, {manuscript:{cols:9, rows:['…']}} ],
  answer:1                  // 複数正解なら answers:[0,2], anyOf:true
}
```

### 同じルールの問題パターンを増やす

`data.js` の `RULE_VARIANTS` に、元のルールと違う部分だけを書きます。元問題と追加パターンは交互に選ばれるため、直前と同じ文章は連続しません。

```js
'RULE-102': [{
  choices:[ {text:'公園へ はしりました。'}, {text:'公園え はしりました。'} ],
  answer:0,
  correctExample:'公園へ はしりました。',
  wrongExample:'公園え はしりました。'
}]
```

- 初期の38ルールには別パターンを実装済み（そのぶんは合計76パターン）
- `choice` / `rewrite` の選択肢は毎回自動でシャッフル
- `order` のカード位置も毎回自動でシャッフル
- 正解番号はシャッフル後に自動計算されるので、データ側は元の並びで指定

### 問題タイプ

| questionType | 必要なキー | 内容 |
|---|---|---|
| `ox` | `statement`, `answer`(true/false) | ○×問題 |
| `choice` / `rewrite` | `choices[]`, `answer` または `answers[]`+`anyOf` | 二択・多択・書き換え |
| `find` | `manuscript`, `answers:[[行,字],…]` | 原稿用紙のおかしいマスをタップ（複数可）。`行`は右から、`字`は上から数える |

### 追加したデータの検証

```
node tools-validate.js
```

必須項目の抜け・ID重複・選択肢と正解番号のずれ・`find` の座標ずれ（空きマスや存在しないマスを正解にしていないか）・原稿用紙が1行の文字数を超えていないかを一括チェックします。
「注意」に出る「行の途中で改行」は、会話文の独立行など意図的なものも含むので、内容を見て判断してください。

※ `find` で**空きマス**を正解にするとき（「。」を入れる位置を選ぶ問題など）は `emptyOk:true` を付けます。
※ 会話文などで意図的に行の途中で改行する場合は、その原稿用紙に `allowShort:[行番号]` を付けると検証スクリプトの警告が出なくなります。
| `slot` | `parts[]`, `answers[]`, `insert` | 「、」を入れる場所を選ぶ |
| `order` | `items[]`, `answer:[順番]` | 出来事の並べ替え |

※ `anyOf:true` を付けると「正解は一つではない」表示になります（気持ち・五感・書き換え問題用）。

### 原稿用紙（manuscript）の書き方

原稿用紙は**縦書き**です。行は右から左へ、字は上から下へ並びます。

```js
manuscript:{ cols:9, rows:['　きのう、公園へ','行きました。'] }
```

- `cols` ＝ 1行に入る文字数（縦に並ぶマスの数）
- `rows` ＝ 行。配列の先頭が**いちばん右の行**、次がその左…
- 1文字＝1マス。`　`（全角スペース）は空きマス
- 行末（いちばん下）にあふれた「、」「。」は**自動で前の字と同じマス**に入ります（本ゲームの正式ルール）
- 「。」の直後の「」」も**自動で同じマス**に入ります
- `merge:false` を付けると、わざとルール違反の見た目にできます（まちがい例用）
- 会話文2行目以降の一字下げは、行頭に `　` を書いて表現します

## 実装済みの固定ルール

- 段落の最初は一マス空ける（RULE-012）
- 句読点を行頭に出さない／行末は最後の字と同じマス
- 会話文は改行、2行目以降も一字下げ、おわりの「。」と「」」は同じマス
- 「そして」＝並列・追加／「それから」＝時間の順序
- 「すごかった」は禁止せず、「何がどうすごかったのか」を書き足す方向に導く
- 不正解でもHPは減らず、ヒントを出して何度でも答えられる
