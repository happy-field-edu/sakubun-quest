# 作文マスター・クエスト

小学2年生向け 作文学習Webゲーム。ブラウザだけで動きます（インストール不要・バックエンド不要・外部ライブラリなし）。

## 使い方

- `index.html` をブラウザで開くだけ（iPad Safari 推奨）
- 進捗は端末内の LocalStorage に保存されます（ログイン不要）
- `file://` で開いても動きますが、保存を確実にするならローカルサーバー経由が安全です

```bash
python3 -m http.server 8777
```

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み（タイトル／マップ／バトル／けっか／作文チェック／きろく） |
| `style.css` | 見た目。色・大きさは `:root` の変数でまとめて変更可 |
| `data.js` | **問題データ・ワールド・キャラクター・チェック項目**（ここだけ触れば問題が増える） |
| `script.js` | ゲームのしくみ（進行・判定・演出・保存）。問題追加では触らない |

## 問題（ルール）の追加方法

`data.js` の `RULES` に 1 オブジェクト足すだけで、そのワールドの出題数・敵HP・星の判定に自動で反映されます。

```js
{
  id:'RULE-009',            // 他と重複しない ID
  world:'w1',               // w1〜w5
  type:'rule',              // rule / skill / school_rule
  category:'genkou',        // genkou / moji / kaiwa / bun / kuwashiku（身につき度の分類）
  skill:'一マス空け', difficulty:1,
  title:'ルール名',
  childExplanation:'子ども向けの説明（作文はかせのセリフ）',
  correctExample:'正しい書き方',
  wrongExample:'まちがった書き方',
  hint:'まちがえたときのヒント',
  questionType:'choice',    // ox / choice / find / slot / order / rewrite
  question:'どちらが 正しいかな？',
  choices:[ {text:'…'}, {manuscript:{cols:9, rows:['…']}} ],
  answer:1                  // 複数正解なら answers:[0,2], anyOf:true
}
```

### 問題タイプ

| questionType | 必要なキー | 内容 |
|---|---|---|
| `ox` | `statement`, `answer`(true/false) | ○×問題 |
| `choice` / `rewrite` | `choices[]`, `answer` または `answers[]`+`anyOf` | 二択・多択・書き換え |
| `find` | `manuscript`, `answers:[[行,字],…]` | 原稿用紙のおかしいマスをタップ（複数可）。`行`は右から、`字`は上から数える |
| `slot` | `parts[]`, `answers[]`, `insert` | 「、」を入れる場所を選ぶ |
| `order` | `items[]`, `answer:[順番]` | 出来事の並べ替え |

※ `anyOf:true` を付けると「正解は一つではない」表示になります（気持ち・五感・書き換え問題用）。

### 原稿用紙（manuscript）の書き方

原稿用紙は**縦書き**です。行は右から左へ、字は上から下へ並びます。

```js
manuscript:{ cols:9, rows:['　きのう、公園へ','行きました。'] }
```

- `cols` ＝ 1行に入る文字数（縦に並ぶマスの数）
- `rows` ＝ 行。配列の先頭が**いちばん右の行**、次がその左…
- 1文字＝1マス。`　`（全角スペース）は空きマス
- 行末（いちばん下）にあふれた「、」「。」は**自動で前の字と同じマス**に入ります（本ゲームの正式ルール）
- 「。」の直後の「」」も**自動で同じマス**に入ります
- `merge:false` を付けると、わざとルール違反の見た目にできます（まちがい例用）
- 会話文2行目以降の一字下げは、行頭に `　` を書いて表現します

## 実装済みの固定ルール

- 段落の最初は一マス空ける（RULE-012）
- 句読点を行頭に出さない／行末は最後の字と同じマス
- 会話文は改行、2行目以降も一字下げ、終わりの「。」と「」」は同じマス
- 「そして」＝並列・追加／「それから」＝時間の順序
- 「すごかった」は禁止せず、「何がどうすごかったのか」を書き足す方向に導く
- 不正解でもHPは減らず、ヒントを出して何度でも答えられる

## 今後の拡張メモ

- キャラクターは `data.js` の `CHARACTERS` の絵文字を画像に差し替え可能

- AIによる作文添削は現段階では未実装（作文チェックは児童の自己チェック方式）
